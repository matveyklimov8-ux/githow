# GitHowTo Project

This is my Hello World project from the GitHowTo tutorial.  
In this project I learned how to use **Git**, branches and basic version control workflow.

## What I learned

During this project I practiced:

- creating a Git repository;
- checking changes with `git status`;
- adding files with `git add`;
- creating commits with `git commit`;
- viewing history with `git log`;
- creating and switching branches;
- using tags;
- undoing changes with `git restore` and `git revert`;
- merging branches;
- resolving merge conflicts;
- using `git rebase`;
- renaming and moving files with Git.
